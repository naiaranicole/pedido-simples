# Pedido Simples

## Sobre o projeto

O Pedido Simples é um sistema web desenvolvido como parte das atividades acadêmicas do curso de Análise e Desenvolvimento de Sistemas, na disciplina de Projeto de Software.

O projeto tem como objetivo auxiliar pequenos comerciantes de bairro na organização de produtos, no controle de estoque e no registro de pedidos, oferecendo uma alternativa digital às anotações em papel.

A proposta surgiu da necessidade de desenvolver uma solução simples, acessível e intuitiva para pequenos estabelecimentos comerciais.

## Objetivo

Desenvolver um MVP (Produto Mínimo Viável) que facilite a rotina de pequenos comerciantes, permitindo organizar informações comerciais de maneira prática e eficiente.

## Funcionalidades previstas

- Cadastro e organização de produtos.
- Controle de quantidades disponíveis em estoque.
- Registro e acompanhamento de pedidos.
- Interface simples e responsiva.
- Navegação acessível para usuários com pouca experiência tecnológica.

## Tecnologias e ferramentas

O projeto foi desenvolvido com o auxílio da plataforma Lovable, utilizando inteligência artificial como ferramenta de apoio à criação e implementação da aplicação.

O GitHub é utilizado para armazenar o código-fonte, acompanhar alterações e organizar o versionamento do projeto.

As tecnologias e bibliotecas específicas podem ser consultadas nos arquivos do repositório.

## Metodologia de desenvolvimento

O desenvolvimento foi organizado a partir da identificação de uma necessidade real de pequenos comerciantes, seguida pelo planejamento de uma solução digital e pela construção de um MVP.

A plataforma Lovable foi utilizada para auxiliar na geração e estruturação inicial do código, enquanto o GitHub foi integrado para permitir o acompanhamento das versões.

O projeto também contempla atividades de revisão de código, testes automatizados, integração contínua e validação com representantes da comunidade, conforme as etapas da disciplina.

## Utilização de inteligência artificial

A inteligência artificial generativa foi utilizada por meio da plataforma Lovable como ferramenta de apoio ao desenvolvimento do MVP.

Sua utilização permitiu transformar os requisitos definidos para o sistema em uma aplicação web, facilitando a prototipação e a implementação inicial.

O projeto integra uma atividade acadêmica que envolve, além da geração do código, a análise de funcionalidades, o controle de versões, os testes e a avaliação da solução desenvolvida.

## Considerações finais

O Pedido Simples busca demonstrar como a tecnologia pode contribuir para melhorar a organização de pequenos negócios, oferecendo uma solução acessível e de fácil utilização.

O desenvolvimento do projeto também proporciona a aplicação prática de conceitos de engenharia de software, organização de código, versionamento e avaliação da qualidade de sistemas.
